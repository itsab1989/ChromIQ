# ChromIQ default sound pack — origin and licensing

Everything in this folder may be used, modified and redistributed freely: it is
either generated by ChromIQ itself or dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No file here
carries an attribution requirement, and none is bundled under a licence that
would restrict ChromIQ's own.

## Synthesised in this repository

All sounds except the one listed below are generated from scratch by
`scripts/make_default_sounds.py` — sine tones, glides, damped resonances and
filtered noise. Re-running that script reproduces them byte for byte (the noise
sources are seeded), so their provenance is the source code itself.

## Recorded, CC0

| File | Source | Licence |

| `task-complete/applause.wav` | ["277021 sandermotions applause-2.wav"](https://commons.wikimedia.org/wiki/File:277021_sandermotions_applause-2.wav) on Wikimedia Commons, originally Freesound #277021 by *sandermotions* | CC0 1.0 (public domain dedication) |

Applause is the one sound that resisted synthesis. A convincing crowd is
hundreds of hand claps plus room acoustics, and every synthesised attempt read
as fireworks or static rather than clapping — so this one is a real recording.

**Processing applied** to the source file, so the result is reproducible: mixed
to mono, resampled 48 kHz → 44.1 kHz, the loudest 1.6-second stretch selected,
an 8 ms fade-in and a 550 ms fade-out applied, then peak-normalised to 0.89.
The result is 44.1 kHz mono 16-bit PCM, matching the rest of the pack.

Attribution is **not required** by CC0. It is recorded here anyway so the
licensing story stays auditable, and because crediting people who give their
work away is worth doing.
