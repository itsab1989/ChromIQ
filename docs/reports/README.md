# Staged reports — general (non-CR30) work

Agents write **incremental** progress here, not only a final report, so nothing
is lost if an agent is killed mid-run.

Convention: `NN-<topic>.md`, appended to as work proceeds.
Every file starts with a status line: `STATUS: in-progress | complete | blocked`.

CR30 (#159) work has its own home: `docs/cr30_reports/`.
